# WeekBloom OAuth consent page

Static GitHub Pages consent UI for the WeekBloom Supabase Auth OAuth 2.1 server.

The page is intentionally limited to sign-in and approval/denial of the OAuth
request. It contains only the public Supabase URL and publishable client key;
no service-role key, client secret, access token, or refresh token belongs here.

The repository and hosted path retain their legacy `weekweave-oauth-consent`
compatibility name so existing OAuth redirect URLs continue to work.

Expected Pages URL:

`https://thomaskim09.github.io/weekweave-oauth-consent/oauth/consent/`
